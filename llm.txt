# Parallex - documentation reference (llm.txt)
Official implementation references for the Parallex research-agent stack, grouped by subsystem.

- https://docs.convex.dev/functions/mutation-functions - Documents transactional mutation functions, database writes, validation, and mutation context.
- https://docs.convex.dev/functions/actions - Covers actions for external APIs and other side effects, plus calling internal queries, mutations, and actions.

- https://docs.convex.dev/file-storage/overview - Introduces Convex File Storage, storage IDs, upload paths, serving files, metadata, and deletion.

- https://docs.convex.dev/file-storage/file-metadata - Shows how to query the `_storage` system table for file size, content type, digest, and creation metadata.

- https://docs.convex.dev/functions/http-actions - Covers HTTP routers, route matching, request and response handling, CORS, authentication, and webhook-style endpoints.
- https://docs.convex.dev/auth/overview - Explains how Convex authentication identity reaches backend functions and how application authorization must be enforced.
- https://docs.convex.dev/auth/convex-auth - Introduces the Convex Auth library and links its setup, provider, and authorization documentation.
- https://labs.convex.dev/auth/setup - Provides the standard `@convex-dev/auth` installation and initialization flow, required auth tables, and React provider setup.
- https://labs.convex.dev/auth/setup/manual - Documents the files, schema additions, environment configuration, and providers required for a manual Convex Auth setup.
- https://labs.convex.dev/auth/config/passwords - Configures the Convex Auth `Password` provider for sign-up, sign-in, password reset, and optional verification flows.
- https://labs.convex.dev/auth/authz/nextjs - Covers server-side Convex Auth in Next.js App Router, protected-route matching, tokens, server data loading, and the currently documented `middleware.ts` integration.
- https://labs.convex.dev/auth/api_reference/nextjs - Lists the client-facing Next.js provider and auth action APIs exported by Convex Auth.
- https://labs.convex.dev/auth/api_reference/nextjs/server - Lists server-side Next.js helpers such as `convexAuthNextjsToken`, `isAuthenticatedNextjs`, middleware context, and redirect helpers.
- https://docs.convex.dev/database/pagination - Documents cursor pagination with `.paginate()`, `paginationOptsValidator`, page results, continuation cursors, and reactive pagination behavior.
- https://docs.convex.dev/testing/convex-test - Shows how to test Convex functions with `convex-test`, Vitest, a supplied schema, and `import.meta.glob` function modules.
- https://docs.convex.dev/production/environment-variables - Explains deployment-scoped environment variables, dashboard and CLI management, and access through `process.env`.
- https://docs.convex.dev/dashboard/overview - Introduces the Convex dashboard for deployments, data, functions, logs, files, schedules, environment variables, and operational inspection.
